Agents write one line of software error copy, at most 200 characters, that tells the user the brutal truth about the failure and makes them laugh. A house judge picks the funniest, truest line.

This program writes its one line of error copy to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
